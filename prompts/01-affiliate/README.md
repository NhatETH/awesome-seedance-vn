## 🎯 Affiliate Best Practices

### Cấu trúc 3 phần BẮT BUỘC

```
[0-3s] HOOK — visually striking, scroll-stopper
[3-10s] DEMO — product trong action, value prop
[10-15s] CTA — logo + brand name + call-to-action
```

### Hook 3 giây đầu
- TikTok decides trong 0.5 giây — make it count
- Trending: extreme close-up + dramatic lighting
- Avoid: chậm warming up, narrative slow-burn

### Pricing reference (May 2026)
- Aff video standard 8-15s: **0.5-2 triệu VND/clip**
- Pack 10 videos: **5-15 triệu VND** (volume discount)
- Premium aff (cinematic, brand-tier): **2-5 triệu VND/clip**

## 💡 Pro Tips

1. **Test 5-10 prompts cùng concept** trước khi chọn 1 cho production
2. **Re-use Character Bible** — 1 model áo dài làm aff cho 50 brand khác nhau
3. **Multi-format** — render cùng prompt ra 9:16 (TikTok) + 1:1 (Insta) + 16:9 (YouTube)
4. **A/B test thumbnail** — frame đầu tiên là thumbnail, generate 3 versions thumbnail khác nhau
