```
A perfect sphere of liquid mercury sitting on a polished mirror surface. The sphere slowly deforms under invisible force into a cube shape, then morphs back into a sphere. Reflections shift smoothly with each transformation, catching subtle highlights.

Seamless loop-ready motion — the ending state matches the beginning state EXACTLY to enable continuous loop playback.

Macro lens extreme close-up. ASMR-satisfying aesthetic with hypnotic mesmerizing quality. Clean minimalist black background with subtle vignette. Soft top-down studio light creating gentle reflections.

Subtle ambient hum sound, very low frequency. Almost no other sound. NO music. NO voiceover.

1:1 square aspect ratio, 24fps, 6 seconds, ultra-smooth motion.
```

## 🐛 Common Issues & Fixes

### Issue 1: Loop doesn't seamlessly connect
**Cause:** Prompt didn't enforce "ending = beginning"
**Fix:** Add explicit:
```
At 0s and at 6s: identical state — perfect sphere, same orientation, same lighting.
```

### Issue 2: Motion too fast / jittery
**Fix:** Replace `slowly deforms` with `imperceptibly slowly morphs over 3 seconds, then morphs back over 3 seconds`.

### Issue 3: Background too busy
**Fix:** Specify `pure black void background, no texture, no gradient, no light reflections except on subject`.

### Issue 4: Reflections look fake
**Fix:** Mercury reflections are tricky. Try:
```
Photorealistic specular reflections following physics. Mirror surface reflects only the sphere itself, no environment reflections.
```
