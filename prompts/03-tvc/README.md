## 📋 Best practices for TVC

1. **Product fidelity tuyệt đối** — sản phẩm phải nhìn giống nhau cross all shots
2. **Beauty pass technique** — material physics on packaging (kính, kim loại, vải)
3. **Hero shot pacing** — sản phẩm được hold 2-5s trong sequence
4. **VO breathing space** — visual không quá busy, để chỗ cho voiceover
5. **Brand color script** — palette consistent với brand identity

## 💡 Quick TVC Template

Use this as starting point for any TVC:

```
[Brand context: Vietnamese luxury jewelry / real estate / fashion brand]
[Product: specific item with material details]

A [3×3 / 4×4] grid storyboard, [16:9 / 1:1] aspect.

CHARACTER (if applicable): [age, ethnicity, build, hair, face, wardrobe]
PRODUCT: [exact specs, materials, colors, dimensions]

Read panels left-to-right, top-to-bottom:

Panel 1: WIDE establishing — world / brand context
Panel 2: Character / lifestyle moment
Panel 3: Product introduction
Panel 4: Hero shot product (THE iconic image)
[...]

STYLE: [Reference: Hermès / Cartier / Louis Vuitton / etc.]
COLOR: [Brand palette]
AVOID: [Generic luxury, busy backgrounds, harsh light]

PRODUCT FIDELITY: Product looks IDENTICAL across all panels showing it.
```
