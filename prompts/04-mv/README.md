## 📋 Best practices for MV

1. **BPM-sync cutting** — calculate BPM, sync cuts to beat grid
2. **Multi-angle choreography coverage** — không chỉ 1 góc, capture từ multiple angles
3. **Hero pose moment** — iconic image cho thumbnail
4. **Color script per song section** — verse cool, chorus warm, bridge dramatic
5. **Outfit consistency** — áo dài / streetwear / costume locked across shots

## 💡 Quick MV Template

```
[Song genre: V-pop / K-pop / ballad / electronic]
[BPM: calculate exact tempo]

A [3×3 / 4×4] grid storyboard, [1:1 generation, will crop later].

ARTIST (consistent identity):
[Age, ethnicity, build, hair detail, face detail, full outfit, makeup, accessories]

SETTING: [Studio backdrop OR outdoor location, lighting setup]

Read panels left-to-right, top-to-bottom:

Panel 1: Establishing — artist in setting, pre-choreo pose
Panel 2: Hero pose — iconic signature pose
Panel 3: Detail / texture
Panel 4-12: Choreography coverage from multiple angles
Final panel: Iconic title-card final image

CUTTING RHYTHM:
Beat sync: [BPM] = cut every [calculate seconds] = [X] cuts/second
Major scene change every 4 beats.

STYLE: [Reference MV: NewJeans, IVE, Aespa, Phương Mỹ Chi, etc.]
COLOR: [Brand palette]
AVOID: [Awkward biomechanics, hand glitches, off-rhythm body positions]
```
