## 📋 Best practices for Documentary

1. **Long static shots** — pacing chậm, hold each shot 3-6s
2. **Wide compositions** — landscape ratios, environment hero
3. **Natural lighting** — golden hour, blue hour, fog, mist
4. **Authentic location detail** — research thật cụ thể (vegetation, architecture, era)
5. **Atmosphere over action** — mood-driven, not character-driven

## 💡 Quick Documentary Template

```
[Location: specific Vietnamese place — Hội An, Đà Lạt, Sa Pa, Mekong, etc.]
[Time: golden hour / blue hour / dawn mist / midday harsh / dusk]
[Mood: contemplative / nostalgic / awe-inspired / melancholic]

A [3×3 grid OR single continuous shot] storyboard, [16:9 OR 2.39:1] cinematic.

SUBJECT: [Environment hero — mention specific landmarks/features]
- Vegetation: [authentic Vietnamese species]
- Architecture: [specific style/era if relevant]
- Atmospheric: [mist, smoke, water, light beams]

CHARACTER (if any, secondary to environment): [minimal description]

Read panels [or beats]:
Panel 1: WIDE establishing — landscape hero
Panel 2: MEDIUM — closer detail, texture
Panel 3: ECU — micro detail (vegetation, water, fabric)
[etc.]

STYLE: [Reference: National Geographic, Studio Ghibli landscapes, 
Trần Anh Hùng cinematography, Wong Kar-wai mood]
COLOR: [Earth tones + specific accents]
PACING: SLOW. Each shot held 3-5+ seconds.
AVOID: [generic "Asia tropical", over-saturated, busy compositions]
```

## 🎯 What-If Format (Sub-Category)

What-If videos are massive on TikTok 2026. Format: take recognizable place + magical twist.

**Anchor + Twist formula:**
- Anchor = recognizable Vietnamese location (Saigon, Hà Nội, Hội An, Hạ Long, etc.)
- Twist = single magical change (jungle reclaim, underwater, ancient era return, etc.)

**Best subjects for What-If:**
- Saigon overgrown by jungle (post-apocalyptic beautiful)
- Hà Nội Old Quarter underwater (Atlantis-style)
- Hội An time-jumped to Champa era
- Hạ Long Bay frozen ice age
- Mekong Delta in distant future
