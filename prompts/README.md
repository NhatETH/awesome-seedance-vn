## 🎯 How to Use / Cách dùng

### Bước 1 — Chọn prompt phù hợp
Tìm theo category. Đọc brief tiếng Việt để hiểu use case.

### Bước 2 — Copy English prompt
Mỗi file có code block sẵn để copy.

### Bước 3 — Customize
Thay đổi các phần `[BRACKETS]`:
- `[CHARACTER]` → mô tả nhân vật của bạn
- `[BRAND]` → tên brand (đã chuẩn hoá)
- `[LOCATION]` → địa điểm
- `[ACTION]` → hành động cụ thể

### Bước 4 — Test ở 480p Fast
Dùng iteration loop 4 bước. Generate 2-3 versions ở Fast (rẻ). Pick best.

### Bước 5 — Final ở 1080p
Generate version final ở 1080p Standard.
