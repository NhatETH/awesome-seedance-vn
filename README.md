## 📺 5 Trending Formats Q2/2026

> Top 5 viral formats trên TikTok #seedance — view trung bình 100K-2M+ mỗi clip

### 🌟 1. HENSHIN — Biến hình anime
Upload ảnh người thật → biến thành warrior/anime version. Khuôn mặt giữ nguyên. **Format đỉnh điểm tháng 5/2026.**
👉 [Tutorial + prompt mẫu](case-studies/01-henshin-transformation/)

### 🌀 2. SATISFYING LOOP — Vòng lặp ASMR
Vật morphing A→B→A. Magic keyword: `seamless loop-ready motion`.
👉 [Mercury Sphere example](prompts/01-affiliate/22-mercury-loop.md)

### 👁️ 3. POV / ORB — First-person 15s
Single continuous shot, camera = mắt nhân vật.
👉 [Knight battle prompt](prompts/02-drama/23-pov-knight.md)

### 🧴 4. ASMR MACRO — Sản phẩm cận cảnh
Extreme close-up + tactile sound design. Beauty community LOVES this.
👉 [Skincare gel example](case-studies/04-asmr-macro-skincare/)

### 🌳 5. WHAT-IF SURREAL — Giả định bất khả
Landmark quen + magical realism twist.
👉 [Saigon jungle example](case-studies/05-what-if-saigon-jungle/)

### Image Generation Models (cho storyboard grid)

Mix nhiều engines để có quality cao nhất:

| Model | Best For |
|-------|----------|
| **GPT Image 2** | Multi-cell grids 4×4 (best agentic, hiểu "panel layout") |
| **Nano Banana 2** | Asian characters, áo dài, hanbok, K-face (best skin tone Asian) |
| **FLUX 1.1 Pro** | Photorealistic skin texture, fabric detail, hands |
| **Recraft V3** | Typography, brand asset, poster |

> **Pro technique:** Multi-engine composite — generate layout trong GPT Image 2, regenerate specific cells trong Nano Banana / FLUX, composite trong Photoshop. Đây là kỹ thuật chỉ documented ở repo này.
