## ⭐ Featured: 16-Panel Master Grid Series

**[16-Panel Master Workflow](02-grid-16-panel/)** là tier cao nhất repo này. 4 templates chuyên sâu:

| Template | Use Case | Pricing VN |
|----------|----------|:----------:|
| 🎵 [Dance MV K-pop / V-pop](02-grid-16-panel/01-dance-mv.md) | Idol agency, indie artist | 5-30tr |
| 👘 [Cổ trang / Period Drama](02-grid-16-panel/02-co-trang.md) | Trần/Lê/Nguyễn dynasty content | 8-50tr |
| 💎 [TVC Luxury Cinematic](02-grid-16-panel/03-tvc-luxury.md) | Jewelry, real estate, fashion premium | 15-80tr |
| 🎬 [Short Film Narrative](02-grid-16-panel/04-short-film.md) | Festival film, brand documentary | 10-200tr |

Mỗi template đều có:
- Research lịch sử / brand cụ thể (không generic)
- Character Bible chi tiết (face/body/wardrobe spec)
- 16-beat outline với filmmaking grammar (180° rule, 30° rule, eye-line match)
- Full grid prompt + motion prompt 3-layer
- Multi-engine composite technique (GPT Image 2 + Nano Banana 2 + FLUX)
- Cost analysis + pricing strategy
- Director references + study list

> **Đây không phải "AI slop 1-prompt video".** Đây là filmmaking-level workflow cho AI video.

## 🔥 Pipeline Overview

### Standard Pipeline (9-panel)

```
BRIEF → ChatGPT/Claude → GPT Image 2 → Claude → Seedance → CapCut → DONE
(5min)    (3min)         (5min)        (3min)   (15min)    (10min)
                                                Total: ~45 min, $3 cost
```

### Master Pipeline (16-panel)

```
CONCEPT → ARC MAP → CHARACTER BIBLE → MULTI-ENGINE GRID → MOTION PROMPT → ITERATION → POST-PROD
(10min)   (15min)   (15min)            (15min)             (10min)         (45min)     (60min)
                                                                          Total: 2-3 hrs, $5-12 cost
```
