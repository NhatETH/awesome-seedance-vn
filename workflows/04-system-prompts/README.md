# 🤖 System Prompts for LLMs

[← Back to workflows](../README.md)

Ready-to-paste system prompts for Claude / ChatGPT / Grok. Set once → generate Seedance prompts in seconds for years to come.

---

## 📂 Available

| LLM | Use Case | Prompt |
|-----|----------|--------|
| 🟣 [Claude Director V2](claude-director-v2.md) | **MAIN** — Director-style for any video | Recommended |
| 🟢 [ChatGPT Storyboard Designer](chatgpt-storyboard.md) | Best for visual / GPT Image 2 grids | For grid heavy work |
| 🟠 [Grok Viral Format Expert](grok-viral.md) | Best for viral / TikTok formats | For trend chasing |
| 🔵 [Gemini Fact Checker](gemini-factchecker.md) | Best for documentary / accuracy | For facts/locations |

---

## 🤔 Which to use?

```
Need... → Use...

Cinematic drama with strong narrative → Claude Director V2
Visual-first storyboards (lots of grids) → ChatGPT Storyboard Designer
Viral TikTok content / meme format → Grok Viral
Real locations/historical accuracy → Gemini Fact Checker
```

---

## 💡 Multi-LLM Workflow

For complex projects, chain LLMs:

```
1. Claude V2 → generates structure + prompts
2. ChatGPT → refines GPT Image 2 grid prompt visually
3. Gemini → fact-checks if real locations/dates
4. Grok → adds viral hook for TikTok cut
5. Final review by you → paste into Seedance
```
