# 🔄 Workflow #5: 4-Step Iteration Loop

> **Save 75% credits.** Beginners burn $50+ per video iterating randomly. Pros use 4-step structured iteration to nail it in $5-10.

[← Back to workflows](README.md)

## 🇻🇳 Quy tắc cốt lõi

> **"Don't iterate on 1080p. Don't iterate on bad prompts. Iterate on quality variants of good prompts."**

Iteration ngẫu nhiên = đốt tiền. Iteration có cấu trúc = tiết kiệm + nâng quality.

## 🎯 The 4-Step Loop

```
┌─────────────────────────────────────────────────────────┐
│  STEP 1: PROMPT QUALITY CHECK (no generation needed)    │
│  → Verify prompt before spending money                  │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 2: 480P FAST TEST (3 versions, ~$1.50 total)     │
│  → Test concept cheap before committing                 │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 3: PROMPT REFINEMENT BASED ON 480P                │
│  → Fix issues identified in step 2                      │
└─────────────────────────────────────────────────────────┘
                        ▼
┌─────────────────────────────────────────────────────────┐
│  STEP 4: 1080P FINAL (1-2 versions, ~$2.50-5)          │
│  → Production-quality render only after concept locked  │
└─────────────────────────────────────────────────────────┘
```

**Total cost:** $4-7 per finished video. **Vs random iteration:** $30-50.

## 📋 Step-by-Step Walkthrough

### Step 1: Prompt Quality Check (FREE)

Trước khi spend credit, verify prompt với checklist:

- [ ] **Subject specific?** (age, ethnicity, distinguishing features)
- [ ] **Action verb present?** (specific motion, not "is doing")
- [ ] **Camera defined?** (shot type + movement + lens)
- [ ] **Setting + lighting specified?** (place + time + light direction)
- [ ] **Style reference?** (director / aesthetic / lens character)
- [ ] **Constraints listed?** (what NOT to do)
- [ ] **Word count 60-150 words?** (Goldilocks zone)

**If any unchecked → fix before generating.** This step costs $0 but saves $5-15 in failed renders.

#### Quick prompt audit example

```
❌ "Beautiful woman walking in forest"
   - Subject: too vague
   - Action: present but weak
   - Camera: missing
   - Setting: vague
   - Style: missing
   - Constraints: missing
   - Score: 1/7. DO NOT GENERATE.

✅ "A 28-year-old Korean woman with shoulder-length black wavy hair, 
   wearing a beige linen dress, walks slowly through a misty pine forest 
   at dawn. Camera tracks beside her at medium shot, anamorphic lens, 
   shallow depth of field. Soft golden light filters through trees. 
   Wong Kar-wai aesthetic, painterly grain. No motion blur on face, 
   no text in frame, hair physics realistic."
   - Score: 7/7. SAFE TO GENERATE.
```

### Step 2: 480p Fast Test ($1.50 total)

Generate **3 versions** of your prompt at 480p Fast resolution:

#### V1: Default
Run prompt as written.

#### V2: Style variant
Same prompt + add: `"More dramatic lighting, increased contrast, deeper shadows"`

#### V3: Pacing variant
Same prompt + add: `"Slower pacing, hold each beat 1.5x longer, contemplative mood"`

**Why 3 versions?**
- Seedance has randomness — same prompt produces different outputs
- 3 gives you a "best of" without breaking the bank
- Cost: $0.50 × 3 = $1.50

#### Watch each video and grade

| Aspect | Pass / Fail |
|--------|:-----------:|
| Character matches intent | ? |
| Action correct | ? |
| Camera move correct | ? |
| Lighting feels right | ? |
| No major glitches (face, hands, morphing) | ? |
| Aesthetic close to vision | ? |

**Pick the version closest to vision** — even if not perfect. Note specific issues.

### Step 3: Prompt Refinement (FREE)

Based on V2 outcomes, refine prompt for known issues:

#### Common issues + fixes

**Issue:** Character face drifts mid-video
**Fix:** Add `"Face IDENTICAL throughout entire video, no morphing across any frame"`

**Issue:** Hands look wonky in close-up
**Fix:** Add `"Hands clearly show 5 fingers, anatomically correct, no merging"`

**Issue:** Camera moves too fast / not at all
**Fix:** Specify exact pace: `"Camera dollies left at walking pace, 1m per second"`

**Issue:** Lighting is flat / too dark / harsh
**Fix:** Specify motivated source: `"Single key light from camera-left at 45° down, soft fill from right at 1/4 stop, gentle falloff"`

**Issue:** Background too busy / distracting
**Fix:** Add: `"Clean uncluttered background, depth of field f/2.8 keeping background soft"`

**Issue:** Aesthetic feels generic
**Fix:** Strengthen reference: `"Specifically Wong Kar-wai's 'In the Mood for Love' aesthetic — 1960s Hong Kong color grading, anamorphic 2x squeeze flares, slight green tint in shadows"`

**Issue:** Character looks too young/old/wrong
**Fix:** Strengthen demographics: `"Exactly 32 years old, mature features visible (slight smile lines around eyes), NOT youthful 20s look"`

### Step 4: 1080p Final ($2.50-5)

Run **1-2 versions** at 1080p Standard with refined prompt.

**Why 1-2 instead of 3?**
- You've already validated concept at 480p
- 1080p is 5× cost of 480p
- Variance reduces at higher resolution (more deterministic)

**If V1 1080p is good** → use it.
**If V1 1080p has minor issues** → run V2 with one more refinement.
**If V1 1080p has major issues** → STOP, go back to step 1, your prompt has fundamental problem.

## 🎓 Advanced: Multi-Variation Testing

For commercial work where you want options:

### A/B/C testing structure

```
Variant A: "Dreamy, slow pace, painterly"
Variant B: "Punchy, fast cuts, vibrant"
Variant C: "Cinematic, anamorphic, film grain"
```

Generate at 480p Fast. Send all 3 to client. Let them pick. Generate winner at 1080p.

This gives client perceived choice + you only pay for 1 production-grade render.

## 🚨 Iteration Don'ts

### ❌ DON'T iterate on 1080p
Costs 5× more for marginal quality difference. Validate at 480p first.

### ❌ DON'T iterate without changing prompt
"Same prompt, generate again" wastes credits. Prompt must change between iterations.

### ❌ DON'T iterate forever
After 3-4 iterations, if not working → fundamental prompt problem. Stop, restart from concept.

### ❌ DON'T iterate at peak hours
Renders slower at peak hours (8-11pm Vietnam). Iterate at off-peak (3-7am) if speed matters.

### ❌ DON'T iterate on large batches
If you have 10 videos to make, don't generate all 10 in 1080p first. Iterate 1, lock prompt formula, apply formula to others.
