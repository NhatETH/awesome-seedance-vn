## 📚 How to Read Case Studies

Mỗi case follow same structure:

1. **Brief** — Original client request (Vietnamese)
2. **Approach** — Workflow chosen + why
3. **Storyboard prompt** — GPT Image 2 prompt used
4. **Motion prompt** — Seedance prompt used
5. **Result** — Final video link/preview
6. **ROI breakdown** — Cost vs price
7. **Lessons learned** — What worked / didn't
