## 🇨🇳 Jimeng / Dreamina

**URL:** [jimeng.jianying.com](https://jimeng.jianying.com)

### Strengths
- ✅ **First to get new features** — Seedance updates appear here first
- ✅ **Generous free tier** — 50-100 credits daily means 1-2 video free per day
- ✅ **Integrated suite** — image gen + video gen in one platform
- ✅ **No subscription required** — pay-per-credit
- ✅ **Best for experimentation** — testing new prompts cheaply

### Weaknesses
- ❌ **Requires VPN** — China-only platform
- ❌ **Chinese UI** — translate extension needed
- ❌ **Phone verification** can be tricky (sometimes need Chinese number)
- ❌ **Customer support in Chinese** — language barrier
- ❌ **TOS in Chinese** — read carefully if commercial use

### Setup walkthrough (5 phút)
1. Get VPN (Astrill, NordVPN, ExpressVPN — China region)
2. Visit jimeng.jianying.com
3. Sign up with phone (international numbers usually work)
4. Verify via SMS code
5. Add credits via Alipay or WeChat Pay (or use credit card via 3rd party)

### Best use cases
- Solo creator experimenting with prompts
- Trying new features before they hit other platforms
- Free tier daily generation for portfolio building

## 🇻🇳 0ai.vn

**URL:** [0ai.vn](https://0ai.vn)

### Strengths
- ✅ **No VPN needed** — Vietnam-direct service
- ✅ **Vietnamese UI + support** — chat support trên Zalo
- ✅ **VND payment** — pay via VND bank transfer, MoMo, ZaloPay
- ✅ **Subscription option** — fixed monthly cost, predictable
- ✅ **API access** — for power users automating workflows
- ✅ **4K support** — high-quality output for premium clients

### Weaknesses
- ❌ **Newer features lag** — sometimes 2-4 weeks behind Jimeng
- ❌ **Less generous free tier** — limited trial only
- ❌ **Smaller community** — less peer support
- ❌ **Documentation in development** — improving but incomplete

### Setup walkthrough (3 phút)
1. Visit 0ai.vn
2. Sign up with email or Google
3. Verify email
4. Choose plan (subscription or pay-per-render)
5. Top up via VND payment methods
6. Start generating

### Best use cases
- Production work for Vietnamese clients
- Stable workflow without VPN dependency
- API automation projects
- Higher-resolution output for paid deliverables
- VN-specific support needs (language, payment, regulations)

## 🎯 Which One Should You Use?

### Decision matrix

| Your Situation | Recommendation |
|----------------|---------------|
| Just experimenting, learning | **Jimeng** (free daily quota) |
| Solo creator, < 20 videos/tháng | **Jimeng** (cheaper per video) |
| Agency / business, > 50 videos/tháng | **0ai.vn Studio** (subscription scale) |
| Need API for automation | **0ai.vn** (better API docs) |
| Want newest features ASAP | **Jimeng** |
| Want stability + VN support | **0ai.vn** |
| Building product for VN market | **0ai.vn** (compliance + speed) |
| Don't have/want VPN | **0ai.vn** |
| Need VND invoice for tax | **0ai.vn** |

### **The smart approach: USE BOTH**

Most pro VN creators do this:
- **Jimeng** for daily experimentation + new feature testing (use free tier)
- **0ai.vn** for paid client work (stable, no VPN, VND invoice)

Cost: ~500K VND/month total covers most freelancer needs.

## 🚨 Common Issues & Solutions

### Issue 1: Jimeng login keeps failing
**Solution:** Try different VPN region (Hong Kong, Taiwan often work). Some VPNs are blocked.

### Issue 2: 0ai.vn renders slower than expected
**Solution:** Off-peak hours (3-7am Saigon time) faster. Or upgrade to higher tier.

### Issue 3: Output quality differs between platforms
**Solution:** Verify both use same Seedance 2.x version. Check generation settings (resolution, sampling steps).

### Issue 4: Payment failing on Jimeng
**Solution:** Try Alipay via international card service. Or use 3rd-party top-up service.

### Issue 5: Generated video has Chinese watermark
**Solution:** Free tier on Jimeng adds watermark. Pay tier removes it. 0ai.vn doesn't watermark.
